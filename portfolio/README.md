## 🌐 Local Development

To run locally:

```bash
# Clone the repository
git clone https://github.com/8348-eng/portfolio.git

# Navigate to folder
cd portfolio

# Start any local HTTP server
python -m http.server 8000
# or
npx serve .
```

Open `http://localhost:8000` in your browser.
